# Opus Juris releases

Installers for the Opus Juris desktop application for Windows, and the manifest the installed application reads to update itself.

This repository holds no source code. Each release carries the signed installer and its update manifest.

To install: download the newest Setup file from the Releases page and run it. Signing in needs a firm code and an invitation from your firm's administrator.
